# Bank of Kigali Loan System

A containerized financial management application built with **Java** and deployed using **Docker**.

## 🚀 Project Overview
The Bank of Kigali Loan System is a backend application designed to manage loan processing and banking operations. By using Docker, this project ensures that the Java runtime environment is consistent across any machine, eliminating "it works on my machine" issues.

## 🛠 Technology Stack
* **Language:** Java
* **Runtime:** Eclipse Temurin (JRE 25 Alpine)
* **Containerization:** Docker
* **Version Control:** Git & GitHub
